CoinGecko review

Disclosure: the button below may become an affiliate link. If you sign up through it we may earn a commission at no extra cost to you. That doesn't change what we write. No star ratings: we don't publish scores we can't back with testing data. Details and prices change, so check the official site.

CoinGecko is an independent crypto data aggregator (founded 2014) that tracks prices, market caps, volumes, exchanges and categories for a very large number of coins. The website is free to use, and it offers a public API with a free tier and paid plans for heavier use.

Good for

  • Checking prices, market caps, supply and links for almost any listed coin
  • Comparing exchanges and spotting where a token trades
  • Builders who want a free/low-cost price API for side projects (this site's sister tools use it client-side)

Skip it if

  • High-frequency or latency-sensitive trading data
  • Unlisted or brand-new tokens that haven't been added yet (use a DEX scanner for those)

Pros

  • Free website with no account needed for basic use
  • Broad coverage of coins, categories and exchanges
  • Public API with a free tier, so you can prototype without paying
  • Portfolio and watchlist features

Cons

  • Free API tier is rate-limited; serious apps need a paid plan
  • Aggregated data can lag or differ from a specific exchange's price
  • Many ads/promoted placements on the free site

Pricing

Website: free. API: free tier plus paid plans. Check CoinGecko's API pricing page for current limits and prices, as they change.

Bottom line

CoinGecko is a well-known, widely used option in its category. Whether it fits depends on the "good for / skip it if" lists above. Try the free tier (where there is one) before paying for anything.
